Cookies & Sessions

Last updated: 19 August 2026

Essential session cookie

When you sign in, IMAGE 24 uses a Secure, HttpOnly, SameSite session cookie so the browser can remain authenticated. It does not contain your plaintext password.

Turnstile

If Cloudflare Turnstile is enabled, Cloudflare may process signals needed to distinguish legitimate users from automated abuse. The widget is used for feedback protection in the current build.

Analytics and advertising

The current build does not require an advertising SDK to operate. If analytics or advertising is added later, update this notice and implement any consent requirements that apply to the audiences served.

Browser storage

Browser-first file processing uses in-memory browser APIs and temporary object URLs for the selected files. Source files are not intentionally persisted by the current tool UI.
