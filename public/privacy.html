Privacy

Last updated: 19 August 2026

1. What IMAGE 24 does

IMAGE 24 provides image and PDF utilities, user accounts, usage tracking and optional Pro subscriptions. This page explains the current data flow of the production build.

2. Files and browser processing

The current browser-first tools process source files locally in your browser whenever the tool can do so. The usage API receives only the tool name when a job is reserved; it does not receive the source file contents. The production build does not create a permanent upload area for browser-first tools.

Some advanced conversions may depend on browser libraries and can behave differently for complex documents. If a future tool requires server-side file processing, IMAGE 24 should disclose that data flow before the file is transmitted.

3. Account information

If you create an account, IMAGE 24 stores your name, email address, a password hash and salt, session records, plan status and subscription identifiers. Passwords are never stored as plaintext.

Job history stores the selected tool, status and timestamp, not the contents of your files.

4. Usage limits and security

IMAGE 24 records daily job counters to enforce the Free (10 jobs/day) and Pro (500 jobs/day) limits. Anonymous usage is associated with a privacy-preserving server-side hash of the request IP and a secret pepper; the raw IP is not stored in the usage table.

5. Billing

Pro subscriptions are designed to use Razorpay. Payment credentials are handled by the payment provider. IMAGE 24 stores subscription identifiers and status needed to grant or revoke Pro access. Payment secrets are kept as Cloudflare Worker secrets and are not placed in browser code.

6. Feedback

Feedback submissions may include the category, selected tool, optional email address and message. Cloudflare Turnstile can be enabled to reduce automated spam. Do not send passwords, payment credentials or other sensitive information through feedback.

7. Cookies and sessions

Signed-in sessions use a Secure, HttpOnly, SameSite cookie. The cookie is used to keep you signed in and is not intended to contain your password.

8. Retention and deletion

Session records expire after 30 days unless refreshed by a new login. Account, usage, job-history and feedback records are retained as needed to operate the service. Before accepting real users, the operator should define a formal retention and deletion schedule appropriate to the jurisdictions served.

9. Your choices

You can stop using the service at any time. Account deletion, data-access and other privacy requests should be sent to support@image24.in.

10. Important note

This page describes the current technical implementation and is not legal advice. Review it with appropriate professional advice before public commercial launch, especially if you serve users in jurisdictions with specific privacy, consumer or data-transfer requirements.
